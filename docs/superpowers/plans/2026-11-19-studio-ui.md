# MXCam Studio 介面骨架 實作計畫

> **給執行的代理：** 必須搭配 superpowers:subagent-driven-development 逐項執行。步驟用勾選框（`- [ ]`）追蹤。
> 做畫面的任務（Task 1、4、5、6）實作者要先載入 `frontend-design:frontend-design` skill。
> 標 🧑‍🔧 的步驟由主對話跟使用者一起做。直接在 `main` 上 commit；路徑 `C:\dev\esp32S3_cam`。

**目標：** 依 `docs/studio-ui.md` 做出完整的 MXCam Studio 介面骨架：三欄版面、功能切換、辨識框、學習、參數、範例程式、系統設定、韌體更新頁；展示模式下所有功能用模擬資料運作；部署到 GitHub Pages。

**架構：** UI 只跟一個 `Device` 介面講話。`RealDevice` 包裝既有的 `MxcamConnection`（M1 只支援畫面和裝置資訊，其他操作回報不支援）；`DemoDevice` 在瀏覽器裡畫模擬場景、跑模擬辨識、保存學習和參數。辨識結果統一用 `Result` 型別（座標以 320×240 為準），M2 的 RESULTS 推送解析成同一個型別。

**技術：** React 19 + TypeScript + Vitest（既有）；`lucide-react` 圖示；自製輕量 i18n（不加套件）；純 CSS + CSS 變數；GitHub Actions `actions/deploy-pages`。

**規格：** `docs/studio-ui.md`（主要）、`docs/SPEC.md` §3、§6.2、§6.3。

## 全域限制

- 所有介面文字都經過 i18n，提供 `zh-TW` 和 `en` 兩份；預設繁體中文；選擇存在 `localStorage`（讀寫都包 try/catch）
- 深色系，強調色琥珀橘 `#F59E0B`；顏色一律用 CSS 變數定義在 `:root`
- 主要設計尺寸 1280×720 以上；小於這個尺寸不能有元素重疊到無法操作
- 座標一律以 320×240 為準，畫到畫面上時才換算
- ID 顏色：ID1–ID8 固定 8 種顏色（同一個 ID 在框、學習列表、結果列表都同色），不能用強調色琥珀橘
- 真板子模式：GET_INFO 的 `functionIds` 沒有的功能顯示灰色，提示「需要更新韌體」；展示模式全部可用
- 不改動 `pc-app/src/protocol/` 和 `pc-app/src/serial/connection.ts` 的既有行為（只能包裝使用）
- 韌體更新頁只有畫面，按下去顯示「即將推出」
- `npm run lint && npm test && npm run build` 每個任務結束都要通過
- commit 訊息結尾加 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

## 審查重點

1. **語言切換漏字**：切成 English 後畫面上還有中文（或反過來）。Task 1 加一個測試：兩份字典的 key 完全相同；Task 7 的實機檢查兩種語言各看一遍。
2. **座標換算錯誤**：畫面放大後框和標籤對不準，拖曳框選學到錯的位置。Task 4 要測「螢幕座標 ↔ 320×240」的雙向換算（含畫面等比例縮放、左右留黑邊的情況）。
3. **展示模式和真板子的狀態互相污染**：切換展示模式後，還留著上一個模式的學習資料、結果或「已連線」狀態。Task 2 要測切換時狀態完全重設。
4. **「未儲存」標示不準**：學習 / 改參數後沒出現，或存檔後沒消失，或什麼都沒改就出現。Task 5 要測這三種情況。
5. **GitHub Pages 子路徑**：部署後資源 404 或重新整理後白畫面。Task 7 部署後實際打開網址檢查。

export interface Result { id: number /* 0 = 未學習 */; kind: 'color' | 'tag' | 'face';
  x: number; y: number; width: number; height: number; confidence?: number }
export interface LearnedId { id: number; name: string; color?: [number, number, number] /* 顏色功能的 RGB */ }
export interface FunctionParams {
  color: { tolerance: number /*0–100*/; minArea: number; maxResults: number /*1–8*/; showNames: boolean }
  tag: { showNames: boolean }
  face: { threshold: number /*0–100*/; maxResults: number /*1–8*/ }
}
export interface SystemConfig { uartBaud: 115200 | 9600; i2cAddress: number; ledBrightness: number /*0–100*/ }
export interface DeviceSnapshot {
  mode: 'real' | 'demo'; status: ConnectionStatus; info?: DeviceInfo
  supported: FunctionId[]; activeFunction: FunctionId | 0
  learned: Record<FunctionId, LearnedId[]>; params: FunctionParams; system: SystemConfig
  dirty: boolean
}
export interface Device {
  snapshot(): DeviceSnapshot
  subscribe(cb: () => void): () => void          // 狀態有變就通知
  onFrame(cb: (frame: FrameSource) => void): () => void
  onResults(cb: (results: Result[]) => void): () => void
  connect(): Promise<void>; disconnect(): Promise<void>
  setFunction(id: FunctionId): Promise<void>
  learnColor(region: { x: number; y: number; width: number; height: number }): Promise<number>
  forget(fn: FunctionId, id: number): Promise<void>; forgetAll(fn: FunctionId): Promise<void>
  setName(fn: FunctionId, id: number, name: string): Promise<void>
  setParams(p: Partial<FunctionParams>): Promise<void>
  setSystem(c: Partial<SystemConfig>): Promise<void>
  save(): Promise<void>; factoryReset(): Promise<void>
  exportConfig(): string; importConfig(json: string): Promise<void>
  dispose(): void

export type FrameSource = { kind: 'jpeg'; jpeg: Uint8Array } | { kind: 'canvas'; draw(ctx: CanvasRenderingContext2D): void }

**檔案：**

**介面：**
```ts
export interface SceneObject { kind: 'blob' | 'tag' | 'face'; x: number; y: number; r: number /* 或半邊長 */;
  rgb?: [number, number, number]; tagId?: number }
export function sceneAt(timeMs: number): SceneObject[]               // 決定性：同一個時間一定得到同一個場景
export function drawScene(ctx: CanvasRenderingContext2D, objs: SceneObject[]): void
export function recognize(fn: FunctionId, objs: SceneObject[], learned: LearnedId[], params: FunctionParams): Result[]

```
- 場景：3–4 個不同顏色、會沿固定軌跡移動的圓；1 個 AprilTag（tag ID 3，畫出黑白方格的樣子即可）；1 個人臉圖案；偶爾有物體移出畫面
- 顏色辨識：學過的顏色跟圓的顏色在 `tolerance` 內就配對到該 ID；沒學過的圓回報 `id: 0`；依面積排序，最多 `maxResults` 個，小於 `minArea` 的不回報
- AprilTag 辨識：回報 `id` = tag ID；人臉：回報 `confidence`，低於 `threshold` 不回報
- DemoDevice 每 100 ms 產生一張畫面（`FrameSource.kind = 'canvas'`）和一次結果；`learnColor` 用 `colorAt` 取色並分配下一個空的 ID（1–7，滿了就 reject）
