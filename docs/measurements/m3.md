# M3 實機量測與驗收

日期：2026-11-19 ・ 韌體 `40f666e`（M3）・ MXCam Studio `594788a` ・ ESP-IDF v5.5.6 ・ OV3660 ・ CPU 240 MHz
人臉模型：`espressif/human_face_detect` 0.5.2（MSR+MNP s8，放在 app 的 flash rodata）・ esp-dl 3.3.15

## 實機驗收（使用者操作 MXCam Studio，全部通過）

1. 連線後 GET_INFO 列出功能 [1, 2, 3]，人臉偵測可選
2. 對著鏡頭：TFT 有粉紅框（第 8 個 ID 色）與 `FACE nn` 標籤，文字方向正常、畫面鏡像；網頁同時有框、`人臉 nn%` 標籤，結果分頁有座標
3. 門檻調高後偵測變嚴格
4. 「最多回傳幾個」設 1 時，兩張臉只回報一個
5. 遮住半張臉／側臉時框消失或信心度下降
6. 快速切換功能 3→1→3→2→3：不當機，過期結果被丟棄（指令驗證）
7. 串流 25 秒：185 張 FRAME、185 筆 RESULTS，沒有傳送錯誤（指令驗證）

## 已知限制

- 門檻低於 50 不會多找到臉：第一階段（MSR）固定 0.5 的門檻只負責提候選框；`face.threshold` 作用在第二階段（MNP）。
- esp-dl 執行中若記憶體配置失敗會直接重開機（C++ 例外關閉）。`mxf_detect` 在記憶體不足（內部 < 32 KB 或 PSRAM 最大區塊 < 256 KB）時跳過該張，只能降低風險。
- 人臉沒有身分辨識，不能取名（SET_NAME／LEARN 對功能 3 回 BAD_PARAM）。
