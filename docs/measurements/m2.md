# M2 實機量測與驗收

日期：2026-11-19 ・ 韌體 `fef9c27` 起（M2）・ MXCam Studio `6c14f13` 起 ・ ESP-IDF v5.5.6 ・ OV3660 ・ CPU 240 MHz

## 實機驗收（使用者操作 MXCam Studio，全部通過）

1. 連線後顯示裝置資訊；顏色、AprilTag 可用，人臉灰色（M3）
2. 框選學會紅、綠、藍三色（ID1–ID3）
3. 網頁與 TFT 同時框出，標籤一致
4. 取名後標籤跟著改變
5. 調整「最多回傳幾個」生效，出現「未儲存」
6. 存到板子後「未儲存」消失
7. 拔電重開後學習資料、名字、設定都還在
8. AprilTag 12 在網頁與 TFT 都辨識成功
9. 鏡像顯示開關切換時，框都對在物體上
10. 存檔／恢復原廠（指令驗證）：改設定＋幫 tag 12 取中文名「測試12」＋SAVE → 重開機後都還在；FACTORY_RESET → 重開機後設定回到預設值、名字清空
11. AprilTag 旋轉角（官方 apriltag-imgs 的 tag 12）：擺正讀數約 −0.5～−1°；轉約 20° 後讀數穩定在 −20°（手機螢幕朝鏡頭，從鏡頭看是逆時針，符合「鏡頭影像中順時針為正」）

AprilTag 角度與四個角以**官方 AprilRobotics 圖片**為準；OpenCV／ArUco 字典產生的 tag36h11 圖案方向相差 180°。

## 實測發現並修正的問題

- **AprilTag 完全辨識不到**：鏡頭送進辨識的影像是鏡像的（M1 用面板翻轉來修顯示方向）。改成鏡頭輸出真實影像、TFT 與 Studio 顯示鏡像（ADR-0010）。修正後板子在 51 張畫面中有 50 張辨識到 tag 12，中心與 OpenCV 差距 ≤ 2.5 px。
- **AprilTag 太慢、內部記憶體快用完**：ESP32-S3 沒有雙精度 FPU，改成單精度並把配置導到 PSRAM。
- **預覽「看起來」紅藍對調**：用合成色塊驗證編碼器顏色正確，是現場光線與白平衡造成，不是程式錯誤。
