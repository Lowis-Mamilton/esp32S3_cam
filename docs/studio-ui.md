# MXCam Studio 介面規格 v0.1

> 狀態：草稿，拷問結論整理於 2026-11-19。屬於 SPEC §6.2 的細節。
> 參考：HUSKYLENS 2 機身介面（深色系、功能切換、學習分配 ID）。只參考**操作邏輯**，版面針對電腦重新設計，不照抄外觀。

## 1. 範圍

- 一次做出**完整的介面骨架**：功能選單、三個功能頁、學習流程、參數、系統設定、韌體更新頁
- 韌體還不支援的部分，用**展示模式**的模擬資料運作；接上真的板子時，依照 GET_INFO 回報的功能清單決定哪些功能可以用
- 韌體更新頁這次只做畫面和流程，按下去顯示「即將推出」（真正的燒錄在 M5）
- 發佈到 GitHub Pages：`https://lowis-mamilton.github.io/esp32S3_cam/`，push 到 `main` 就自動更新

## 2. 版面

主要設計尺寸 1280×720 以上；更小的螢幕不特別支援，只保證不會壞掉。

```
┌─────────────────────────────────────────────────────────┐
│ MXCam Studio   ● 已連線 0.1.0  [展示模式] [中/EN] [連線] │ 上方列
├────────┬───────────────────────────────┬────────────────┤
│ 功能    │                               │ [結果][學習]    │
│ ▣ 顏色  │        即時畫面（大）           │ [參數][程式]    │
│ ▣ Tag   │     辨識框 + ID 標籤            │                │
│ ▣ 人臉  │     中央十字                    │  （分頁內容）    │
│ ────── │                               │                │
│ ⚙ 設定  │                               │                │
│ ⬆ 韌體  │  fps · KB/s                    │ [存到板子] 未儲存│
└────────┴───────────────────────────────┴────────────────┘
```

- **上方列**：產品名稱、連線狀態和韌體版本、展示模式開關、語言切換（繁中 / English）、連線 / 中斷按鈕
- **左側功能列**：顏色、AprilTag、人臉偵測；分隔線下方是系統設定、韌體更新
  - 接上真板子時，GET_INFO 沒列出的功能顯示**灰色**，滑鼠移上去提示「需要更新韌體」
  - 展示模式下全部都能用
- **中間**：大的即時畫面（320×240 等比例放大）、辨識框、中央十字，左下角顯示 fps 和 KB/s
- **右側分頁**：
  - **結果**：目前每個辨識結果的 ID、名稱、x、y、寬、高（R4 實際收到的數字）
  - **學習**：已學習的 ID 列表（顏色色塊、名稱可編輯、單獨刪除），「全部忘記」要確認
  - **參數**：目前功能的參數（見第 4 節）
  - **程式**：目前功能的 Arduino 範例程式（用 MXCam 函式庫），有「複製」按鈕；API 先照 SPEC §6.3，M4 再對齊
  - 底部：「存到板子」按鈕；有沒存的變更時顯示「未儲存」

## 3. 辨識框和標籤

| 情況 | 樣式 | 標籤 |
|---|---|---|
| 還沒學習的目標 | 白色細框 | 類別，例如「顏色」 |
| 已學習的顏色 | 該 ID 的固定顏色（ID1–ID8 各一種） | `ID1 紅色積木`；沒名字就 `ID1` |
| AprilTag | 依 tag ID 取固定顏色 | `Tag 3`；有名字就 `Tag 3 起點` |
| 人臉 | 固定顏色 | `人臉 92%` |

## 4. 功能參數

| 功能 | 參數 |
|---|---|
| 顏色 | 顏色容許範圍、最小面積、最多回傳幾個（1–8）、是否顯示名稱 |
| AprilTag | tag 家族（固定 tag36h11，只顯示）、幫 tag ID 取名、是否顯示名稱 |
| 人臉偵測 | 偵測門檻、最多回傳幾個（1–8） |
| 共用 | 幫 ID 取名；設定**匯出成 JSON 檔 / 從檔案匯入** |

## 5. 顏色學習

- **框選**：在畫面上拖曳一個框，取框內的顏色，分配下一個 ID
- **學習中央**：按鈕，學中央十字所在位置的顏色（HUSKYLENS 的方式）
- 學到的顏色可以單獨刪除；「全部忘記」要確認
- 最多 7 個顏色 ID（SPEC §3）

## 6. 系統設定頁

- 裝置資訊：韌體版本、git、序號、解析度
- 通訊：UART 鮑率（115200 / 9600）、I2C 位址（預設 0x5A）
- 狀態燈（RGB LED）亮度
- 恢復原廠設定（要確認）
- TFT 背光是硬體接死的，**不提供亮度設定**；介面語言是網頁自己的設定，放在上方列

## 7. 生效與儲存

- 調參數、學 ID、取名字會**立刻生效**
- 按「**存到板子**」才寫進 flash；沒存時顯示「未儲存」
- 沒存就斷電，板子重開後回到上次儲存的狀態

## 8. 展示模式

- 不用接板子，網頁自己用程式畫出模擬場景：幾個會移動的彩色圓形、一張 AprilTag 圖、一個簡單的人臉圖案
- 模擬的辨識結果跟著場景移動；學習、取名、參數、存檔都能完整操作（存在瀏覽器記憶體裡，重新整理就清掉）
- 上方列明顯標示「展示模式」，避免誤以為接上了板子

## 9. 外觀

- 深色系；強調色**琥珀橘**（約 `#F59E0B`），跟 HUSKYLENS 的藍 / 青色區隔
- 產品名稱顯示「MXCam Studio」，暫時不放 logo
- 介面語言：繁體中文、English，可切換，記住使用者的選擇
